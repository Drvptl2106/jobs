# Master CV

Upload your master CV here as **`master_cv.pdf`** (or `master_cv.docx`).

On your phone: open this repo in the GitHub app or github.com → `cv` folder → **Add file → Upload files**.

Claude converts it to `master_cv.md` (plain text it can read quickly) and uses only facts from it
when scoring jobs and writing tailored CVs. Replace the file any time your CV changes.
